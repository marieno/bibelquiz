# Bible Tycoon V24.3 — Métiers animés

Ajout de petites séquences 3D déclenchées après les actions confirmées : ouvrier se déplaçant vers une ferme, un arbre, un enclos, une maison ou un marché; accessoires portés et gestes de travail. Les animations ne changent pas les ressources, qui restent gérées par le jeu ou le serveur. Les cultures conservent leur croissance temporelle.

Limites : modèles géométriques simples; les ouvriers apparaissent près du lieu et non depuis une maison; en multijoueur les animations distantes dépendent des changements détectables dans les compteurs; tests sur vrais appareils nécessaires.
